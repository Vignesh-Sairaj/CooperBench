# Results

Each folder is one benchmark run. Start with [`notes/runs.md`](../notes/runs.md), which lists every run with its settings, the question it answers, and its result.

In each run folder:

- `summary.md` is the page to read: what the experiment was, results, per-pair outcomes, and what we saw in the traces.
- `pairs.csv`, `agents.csv`, and `run.json` hold the data for your own analysis (see [`notes/results_format.md`](../notes/results_format.md)).
